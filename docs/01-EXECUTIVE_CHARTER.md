# OmniScore AI — Executive Project Charter & Product Vision

## 1. Executive Vision
OmniScore AI is built to democratize technical profile evaluation by delivering an AI-driven, multi-modal career intelligence platform. Traditional applicant tracking systems (ATS) rely on brittle, unexplainable keyword matching that frequently rejects qualified candidates while failing to quantify demonstrated proof-of-work (code repositories, data visualisations, interactive dashboards). OmniScore AI solves this by unifying resume NLP parsing, vector-based skill gap matching, multi-platform portfolio harvesting (GitHub, LinkedIn, Tableau Public, Power BI), and an explainable 4-pillar scoring algorithm.

---

## 2. Core Value Proposition

| Stakeholder Group | Core Pain Point | OmniScore AI Solution |
|---|---|---|
| **Job Candidates** | Black-box rejection by ATS without feedback | Transparent 0–100 score, vector skill gap analysis, line-by-line bullet rewrites |
| **Tech Recruiters** | Manual review of hundreds of unformatted CVs | Multi-tenant recruiter candidate pool candidate candidate pool matrix with automated ranking |
| **Enterprise Organizations** | Hiring bias and high cost of false negatives | PII-redacted, objective proof-of-work evaluation across code & visual analytics |

---

## 3. Product Principles
1. **Explainable AI (XAI)**: No black-box scores. Every point awarded or deducted is backed by empirical findings.
2. **Multi-Modal Proof of Work**: Skills are validated against actual code commits, Tableau workbooks, and DAX data models.
3. **PII Safety & Privacy**: Personally Identifiable Information is stripped prior to LLM processing.
4. **Graceful Degradation**: 100% operational offline without mandatory external API keys.
